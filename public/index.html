      Fork 对话
      
      
      
      
      
      此 Agent 尚未提供已验证的原生 Fork，请使用 Handoff 模式。
      
      
      
      实验性功能：交接可能造成信息遗漏或漂移，并产生额外模型费用。接受后继续。
      
      
      原对话保留。新对话使用独立目录，复制当前代码改动和附件；不复制依赖缓存，不自动提交或推送。
      
      
      
      
      
          
    
      
      切换 Agent
      
      
      
      
      将自动读取任务记录并核对项目，由目标 Agent 在新会话中接手。上下文无法完整互通，可能造成信息遗漏、理解偏差或信息漂移。
      
      
      项目文件、附件和历史记录会保留。交接需要调用目标模型，可能产生费用；失败时保留原 Agent。是否接受并继续？
