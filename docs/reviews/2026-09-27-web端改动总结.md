## 逐项说明

### P0 侧栏按"谁需要你"排序

- **协议**：`sessions[].attention?: "waiting" | "finished"`。
  - `waiting`：该会话有未回答的 agent 对话框。
  - `finished`：一轮运行结束时**没有任何浏览器附着**在该会话上。
  - 任一浏览器打开该会话即清除；变化时 Host 重新广播 `sessions`。
- **Host**：`HostSession.attention` getter（`src/host/session.ts`），纯派生态，不持久化（INV-S3）。
- **前端**：新增 `public/sidebar.js`（纯逻辑、无 DOM）：`orderSessions()` 排序 waiting > finished > running > 其它，同级按更新时间；`sessionGroups()` 输出 需要你 / 运行中 / 时间分组 / 本机终端会话。`app.js` 只负责渲染。`timeGroup` 从 `render.js` 移入此文件（`render.js` 仍 re-export，调用方不变）。

### P1 帐号用量条

- **协议**：`stats.rateLimits?: { fiveHour?, weekly?, plan? }`，每个窗口 `{ usedPercent, windowMinutes, resetsAt|null }`。
- **适配器**：`CodexSessionFactory.readRateLimits()` 调 `account/rateLimits/read`（60 s 缓存），并通过 `rpc.ts` 新增的 `subscribeGlobal()` 接收 `account/rateLimits/updated` 推送。窗口按**时长**分类（≤24h → 5 小时窗，否则周窗），不依赖 `primary/secondary` 槽名。API-key 登录（读取失败）只探测一次，之后 `rateLimits` 缺省，stats 其它字段照常。
- **前端**：`#usage` 芯片；`usageBadge()` 给文本与等级（ok / warn ≤25% / danger ≤10%），`formatReset()` 给"1 小时 30 分后重置"。
- **提示**：两位用户共用 VM 上同一个 Codex 帐号，所以看到的数字相同——这正是要它的原因。

### P2 停靠式 diff 审阅

- 窗口宽度 ≥1100px 时点击"本轮改动"打开右侧 `#diff-panel`（`.app.diff-docked` 三列布局）；否则仍用弹窗。缩窗时停靠面板自动转为弹窗。
- 面板：文件列表（路径、+/−、新增绿 / 删除红划线，点击跳到对应段）+ 按文件分节的 diff 正文（sticky 文件头）。
- 面板开着时每次 `turn_diff` 事件都重新渲染（rAF 合并），所以一轮持续编辑的过程可以边跑边看。
- `patchFiles()`（`sidebar.js`）按 `diff --git` / `---`/`+++` 切分文件并识别新增/删除。

### P3 终端会话可见 + 接管

- **协议**：`sessions[].source?: string`，来自 Codex `thread.source`（`appServer` 是网页开的；`cli` / `exec` 是 VM 管理员在终端开的）。
- **可见范围**：仍受 `thread/list {cwd}` 与 `ownsThread` 限制——只列**同一工作目录** `<WORKDIR>/<user>` 下的线程，其它目录的终端会话不会出现。
- **接管**：打开即 `thread/resume`。如果另一个进程仍在跑 turn：
  - `opened.state.isStreaming = true`，发消息得到 `busy`；
  - 该 turn 不会给我们任何通知，所以 `CodexSession.getState()` 对"不是本 Host 发起的 turn"改为重读 `thread/read` 的状态；
  - `HostSession` 新增 `externalPollMs`（默认 3 s，`HostServerOptions.externalPollMs` 可调）轮询，发现空闲后向浏览器发布 `agent_settled`，之后即可正常对话。
- **已知边界**：若网页先打开空闲线程、终端随后在同一线程开新 turn，Host 无法察觉；下次打开会正确。

### P4 传输下载加固

- `TransferServer.download()`：在原有的字面路径检查之外，新增 `withinRealRoot()`（根与文件都 `realpath` 后比较，防 symlink 逃逸）与 `isCredentialFileName()`（`auth.json`、`.credentials.json`、`.netrc`、`.env*`、`id_*`、`*.pem`、`*.key`、`*.p12`、`*.pfx`、`credentials(.json)`、`known_hosts`）。inbox 列表同样隐藏这些名字。
- 新增 `docs/INVARIANTS.md`：INV-T1..T4（传输）、INV-S1..S4（会话）、INV-I1..I2（身份），测试按编号引用。
