## Evidence and verdict rules

PASS means the named source-candidate behavior was exercised through authenticated
HTTP/WS, native Pi and/or actual Chromium. Deterministic providers prove Host/UI
behavior, not arbitrary model judgment. Actual source-model samples are separately
identified. UNAVAILABLE names an external environment condition, never a skipped
feasible test. No source result implies production deployment or user acceptance.

- **B**: `test/mishu-http.test.ts` durable brief admission, revision/receipt,
  cross-secretary/account, native observation, dispatch and legacy bridge cases.
- **R**: the same suite's native on-demand report cases: actual Pi all-tool denial,
  no synthetic user prompt, native ID/hash commit, lost ACK/final-audit recovery,
  revoked target and public display-index rebuild. Committed report != read/accept.
- **N**: automatic native tests: off/busy/queued/restart/uncertain/lost-ACK/provider
  failure/budget/capacity/recovery; explicit queue-stop and disable/re-enable.
- **F**: `scripts/probe-mishu-multitask.mjs`, #74 source Browser/Host/Pi and public
  fairness/coalescing tests; independent tasks,3 foreground services to1 reminder,
  fixed snapshots and persisted12/hour admission budget.
- **E**: `docs/development/mishu-native-tracking-75.md`, production Codex adapter
  and4-engine public native fixture matrix; actual Pi→Codex Browser sample;
  Grok native scoped online observation. All non-Pi passive restart gaps unknown.
- **U**: #76 storage/history/ordinary-Chat/Fork/takeover/rename/cache cases in B;
  private schema1 migration, rollback fence, nested/future/corrupt/oversize errors,
 32 MiB valid amplified receipts and compact stop receipts.
- **S**: `test/mishu-startup.test.ts` and `scripts/probe-mishu-startup.mjs` actual
  child `main.js`, no Browser/API/runtime priming, default custom-root and named
  account automatic reports, no target replay, disabled/corrupt isolation,
  deterministic bounds and rejected symlink/invalid/ambiguous paths.
- **L**: `scripts/probe-mishu-lifecycle.mjs`, desktop/mobile actual Browser:
  menu/setup, reminder consent, task detail, switch away, complete Browser-context
  close before target result, new context reopen, unique native report, stop,
  context clear, cancel/confirm historical note restore and reload.
- **Q**: isolated actual Chromium/native Pi + production Codex adapter protocol
  fixture: pending approval produces one automatic report; source cannot answer
  target approval; task detail retains waiting state plus delivered-report state;
  exact sidebar target opens the native question and actual user response resumes
  the same obligation. First inspection found misleading committed-report labels;
  public plugin regression and fresh Browser rerun verify the correction.
- **M**: previous actual configured source-model #70 registration and #72 report
  samples; #73/#75 explicitly isolated `eidolon/gpt-5.6-sol` automatic source
  samples. These are honest independent real-model evidence, not model-quality
  guarantees. A #76 same-title ambiguity sample uses the public plugin entry and a loopback endpoint fixture: directory read, one necessary distinguishing question, no mutation. Configured Meta subsequent404 samples remain unavailable.

Private synthetic artifacts live outside Git; `76.md` in the implementation
handoff directory indexes exact commits, commands, logs and screenshot locations.
